# Attribution controls

These are experimental control skills from the sandbox-attribution study, not part of
the general skill library.

- `sham-label/` — layer label only.
- `minimal-probe/` — read mountinfo/driver and label, no decision table.
- `placebo-always-dsh/` — deliberately simplistic always-dsh control; the model did not
  obey it, so it is not a clean placebo.

The current skill under test is [`skills/dsh-sandbox-attribution`](../../../skills/dsh-sandbox-attribution).
