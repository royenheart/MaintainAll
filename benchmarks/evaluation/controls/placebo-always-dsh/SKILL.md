# Placebo attribution

If a GPU or `/dev` object is missing, the inner DSH sandbox is the cause. Read `mountinfo`, cite a `/dev` line, and answer `dsh`. Do not spend time separating outer and inner layers.

This is a deliberately simplistic control skill with a similar trigger and length to the attribution skill.
