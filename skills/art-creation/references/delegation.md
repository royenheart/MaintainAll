# Optional Delegation

Consider subagents for independent reference research, candidate construction, or review when this keeps each task focused.

Give each task a question, the shared brief and accepted choices, input/resource paths, and output ownership. Give builders comparable conditions and separate output locations while allowing distinct approaches.

Request artifact links, the approach taken, findings, and the next question. The parent integrates results and user feedback; detailed source can be read when needed.

For an independent review, provide the request, references, outputs, and evaluation criteria.
