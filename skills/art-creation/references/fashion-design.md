# Fashion and Avatar Design

Use the parent analysis or iterative workflow for clothing, costumes, accessories, and virtual characters. Carry the accepted character identity into each study and introduce vocabulary through visible comparisons.

Consider silhouette, proportions, garment structure and layering, fabric behavior, color roles, decoration, attachment, and movement. Use reference views to propose the visible and hidden construction. Texture controls surface appearance; geometry controls silhouette and volume.

Relate the outfit to its use and viewing scale. Compare candidates on a consistent character, pose, framing, and rendering setup. Choose silhouette studies, flat designs, multiple views, material samples, or playback according to the current question.

| Current question | Useful representation or route |
|---|---|
| Character identity, silhouette, palette, decoration placement | [Canvas design](../methods/canvas-design/SKILL.md) and [visual variants](../methods/visual-variants/SKILL.md) |
| Garment parts, dimensions, panel edges, seam relationships | Editable patterns or procedural geometry; [procedural systems](procedural-systems.md) |
| Volume, fit, viewpoint, drape, attachment | [Scene 3D](../methods/scene-3d/SKILL.md) with an appropriate available backend |
| Secondary motion or deformation | [Motion studies](../methods/animate/SKILL.md) and actual target-runtime checks |
| Live2D, VRoid, or real-time model delivery | [Avatar delivery](avatar-delivery.md) |

For vague qualities, use [Intent and evidence](intent-and-evidence.md) to test a few interpretations. Useful observations include relative dimensions, spacing, attachment, visible intersections, material response, motion timing, and user comparisons.

Move from concept to construction and runtime playback as the design develops. Use [Tool capabilities](tool-capabilities.md) for the selected application backend.
