# Art Creation

Turn references and rough ideas into observable design decisions, visible alternatives, and an executable creative brief. The user does not need specialist vocabulary.

## Capability index

| User need | Capability | Read |
|---|---|---|
| Understand a supplied image, webpage, or design; learn how to describe its style | Style analysis with direct annotation and a two-chapter teaching report | [Style analysis](references/style-analysis.md) |
| Start with a vague idea, sketch, or reference and discover the desired result through feedback | Progressive creative exploration with contrasting previews and controlled refinement | [Iterative creation](references/iterative-creation.md) |

Select the relevant capability. When both are requested, use analysis to inform exploration. Use the two-chapter format for a full analysis report and compact comparisons for exploration rounds.

## Working approach

- Write reports and creative guidance in accessible Chinese unless the user requests another language. Explain a technical term on first use.
- Turn observations and user preferences into concrete design choices.
- Prefer natural language and inspectable programs: text, source, geometry, pixel statistics, timelines, SVG, HTML/CSS, canvas, procedural models, or frame-based rendering. Use multimodal assistance for perceptual questions these representations leave unresolved.
- Display annotations on the supplied material and render alternatives for comparison.
- Carry the requested medium, content, and accepted choices into each iteration; vary unresolved properties through user feedback.

For concrete inspection, overlay, rendering, and motion methods, read [Programmatic visual methods](references/visual-methods.md) when needed.

Progressive disclosure follows `Art Creation -> relevant capability -> chosen method -> relevant resource`. The [method index](references/iterative-creation.md#detailed-description-and-construction-methods) selects construction guidance; the [resource index](references/resource-index.md) maps details and executable starters. Follow the branch that answers the current question.
