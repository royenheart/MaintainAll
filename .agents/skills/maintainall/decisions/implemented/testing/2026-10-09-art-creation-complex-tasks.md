# Decision: Relationship-based creative task evaluation

Status: implemented — twelve reference-driven turns and a frozen artifact review establish the bounded pilot result, without a demonstrated skill gain.

## Problem

The creative smoke tests specify element IDs, small fixed canvases, and output fields. Both skill versions satisfy their mechanical checks. Successful native generation and reload establish runtime availability but do not establish design fidelity, legible hierarchy, garment construction, or preservation of scoped preferences.

## Decision

Retain the smoke tests and add two three-turn reference-driven tasks: original virtual-performer costume studies and an exhibition identity across poster and mobile formats. Four verified Met public-domain images have exact hashes and provenance. The [Chinese research report](../../../../../../docs/research/art-creation-complex-2026-10-09/report.md), [execution plan](../../../../../../docs/research/art-creation-complex-2026-10-09/plan.md), and [results](../../../../../../docs/research/art-creation-complex-2026-10-09/results.md) document the bounded pilot. Four additional task designs are not counted as executed cases.

Keep evaluation rubrics outside the model workspace. Specify the minimum editable/rendered handoff, not the construction method. Evaluate contextual relations with anchored ordinal judgments and evidence notes; report unavailable evidence separately. File hashes apply only when a complete artifact is explicitly frozen. Geometry counts, source length, and self-reported quality are not visual quality proxies.

The benchmark implementation lives in the independent research worktree. Authentication remains on the host CLI; generated commands have filesystem isolation, disabled networking, read-only declared references, and exact session resumption. Model-generated programs are not executed on the unrestricted host. Twelve calls use the same model alias, effort, inputs, renderer, and limits without retries. Immutable result rows determine execution completion; the stored manifest label is not a completion verdict.

The root agent inspects 28 unique PNGs across 48 preview slots and freezes all 94 applicable atom-turn ratings before reading the arm map. This single-agent artifact review does not constitute independent human preference validation. The [frozen rating record](../../../../../../docs/research/art-creation-complex-2026-10-09/quality-ratings.json) remains separate from mechanical checks and has SHA-256 `ab70418c3c78ec441e05a40490c0f6a5f9b941812d5c04379ef4132f530da7d5`.

## Alternatives considered

- Increase object counts or mesh resolution: measures output volume and can reward clutter without testing intent.
- Add detailed construction instructions to every prompt: teaches the answer and repeats the existing ceiling.
- Import a text-to-image benchmark score wholesale: does not evaluate editable deliverables, tool execution, or scoped multi-turn acceptance.
- Replace the runtime with Harbor in this pilot: does not resolve task/rubric discrimination and adds migration scope.
- Automatically grade visual atoms through source parsing or self-scores: confuses declarations and delivery format with visible quality.

## Consequences

All twelve turns pass delivery checks and preserve reference bytes; independent source reconstruction remains unverified. The framework has twenty offline tests, with twenty-three in the wider discovery scope, and seventeen no-model sandbox/renderer doctor checks pass. Mechanical quality remains `unassessed`; the separate review status is `manual_review` with no automatic aesthetic pass.

Both versions receive partial ratings for initial cross-view/attachment clarity and final lightweight-material expression. The current exhibition has one additional partial rating for initial small-card readability. The first-round reading-order atom is withheld for both versions because its hidden requirement exceeds the brief. Frozen cards and ratings preserve that alignment exception rather than silently changing the standard.

The two tasks establish no stable version separation or quality gain. Current-version time and uncached usage are higher in this single fixed-order run. Repeated correlated ratings are not independent samples. Synthetic feedback, single-agent review, static previews, and an unpinned service revision limit interpretation; physical cloth, rigging, motion, and target-application compatibility remain outside this pilot. No task-specific skill rules are added.
